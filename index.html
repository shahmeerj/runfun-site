Run Fun

Run together, wherever you are.

Group running app for Android and iOS

Run Fun lets a group of friends run together. One person starts a lobby and shares a 6-digit code. Everyone who joins appears on a live map while they run, can chat and send voice notes, and gets a summary at the end with distance, pace, splits and lobby awards.

  • Live group map with every runner's position during a run
  • Accurate GPS distance, pace, per-km splits, pace and elevation graphs
  • Lobby awards: fastest runner, fastest km, longest distance and more
  • Chat and voice notes inside each lobby
  • Friends, run history, streaks and personal records
